# v0.8.33

上一版让插件市场与模型页同时支持 web 档与桌面档，但实现上是「web 一套、桌面再平行一套」：两套 IPC 命令、三种变更结果的说法、四处各自探测的桌面应用状态，同一行配置还有两个修改入口。本版把这些合并成一份——**用户可见的功能不变**，修掉了合并过程中暴露的两处缺陷。决策补记在 `docs/adr/0012`。

## Fixes

- **桌面 tab 不再能关掉桥接插件**：「插件 → 桌面应用」tab 的插件行开关里还列着用户自己装的插件，其中包括桥接插件本身——市场把它当受管插件不给停用，这里却能关，关掉后本应用就失去通往桌面档的通道。现在桌面 tab 只列内置 bundle 及其插件行，用户装的插件只在市场里管理（真机验证时测出）
- **模型页不再信过期的「已连接」**：桌面应用状态改为全应用共享后，切到模型页的桌面档会先等本次检测结果再决定显示编辑器还是去向；此前若桥接刚断开，会先挂上编辑器、读一次必然失败的配置并弹出错误

## Changes

- **一个变更去向**：web 档与桌面档、市场与桌面 tab 对「这次改动去哪了」用同一套说法——已生效、重启后生效、被更高优先级的层覆盖、被取消、无需改动。web 档的启停（下次启动 dsh web 生效）与重复启停（无需改动）也归入其中，提示措辞不变
- **默认模型与 AI 提供商只在模型页编辑**：桌面 tab 的原始配置编辑不再列出这两行，并提示去模型页改——同一行配置不留第二个修改入口
- **桌面应用状态全应用一份**：首页卡片、桌面 tab、模型页、市场角标读同一份状态，同时发起的刷新只实际探测一次
- 复制桥接包规格的提示改为「包规格已复制」（原为「地址已复制」，上一版起它已不是地址）
