# v0.3.10

修复 Tailscale 客户端演进后登录名解析必然失败、导致远程授权整体失效的问题。

## Fixes

- **远程访问失效而「本地正常」（allowlist 静默降级）**：Tailscale 客户端更新后 `tailscale status --json` 的 `User` 表 key 与条目内 `ID` 字段不再一致，而登录名解析按 `Self.UserID` 查表 key——必然落空。后果分两条路径：一键启动在「检查 Tailscale 身份」步骤直接失败；`dsh_start_web`/安装后重启等路径经 `runtime_auth_context` 静默降级为 `local-only` allowlist，服务正常启动、本地 loopback 直放不受影响，但所有远程请求（登录名不在 allowlist）一律 401/403——无论是否配置 capability 都失效，与授权配置完全无关
- **修复方式**：解析改为先按条目 `ID` 字段匹配 `Self.UserID`（新形态），条目无 `ID` 字段的旧形态退回按表 key 匹配；附真实漂移形态的回归测试

## 验证

- 以实机当前 `tailscale status --json`（`Self.UserID` 与 User 表 key 相差 1）验证解析恢复输出 `sperictao@gmail.com`
