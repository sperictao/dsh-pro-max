# v0.6.1

修复 v0.6.0 插件市场「发现 / 已安装」页面无法滚动的问题。v0.6.0 的二级导航改造在页面中引入了中间 flex 层（`main.flex.flex-col`），该层缺 `min-h-0`：作为 `h-screen overflow-hidden` 布局链上的 flex 子项，其自动最小尺寸等于全部内容高度，拒绝收缩到视口内，内层内容区的 `overflow-y-auto` 永不触发，超出一屏的部分被 body 的 `overflow-hidden` 直接裁剪——目录内容超过一屏后无法滚动查看。已安装页为同一结构，同样受影响。

## Changes

- **市场页根节点补 `min-h-0`**：flex 链恢复收敛（与 `#root` 同款习惯），二级导航条保持固定，发现/已安装两页内容区恢复滚动

## 验证

- 带 40 条 mock 目录的页面实测：修复前 `#market-view` 底边溢出视口（3437px / 800px 视口）、内容区不可滚、最后一张卡不可达；修复后 main 收敛回视口，内容区可滚、最后一张卡可见
- `vitest`：41 项全部通过；`tsc --noEmit` 无错误
- `pnpm run check:release -- --tag v0.6.1`：版本三处一致、release notes 存在、bundle resources 路径有效

## 升级说明

- 仅一行为修复，无配置与数据迁移；v0.6.0 用户建议直接升级
