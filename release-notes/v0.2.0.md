# v0.2.0

dsh 版本检测宽松化 + 授权插件可卸载。

## Changes

- **dsh 版本兼容判断宽松化**：从「精确等于锁定版本（0.1.0-rc.6）」改为「不低于锁定版本」。安装了更新版 dsh（rc.7/rc.8 及以后）的用户不再被判定为「版本不受支持」，也不会被强制回退；锁定版本仍是 Launcher 验证过的最低版本与「修复」的安装目标
- **高于验证版本的风险提示**：dsh 实际版本高于 Launcher 验证过的兼容栈时，集成卡片如实提示「授权插件可能不兼容」，不阻断使用
- **授权插件可卸载**：集成卡片新增「卸载授权插件」按钮（`dsh plugin --profile web remove`，同步清理 profile 的 dependencies 与 bundles，幂等）。纯本地用户可摆脱 rc 钉版插件；卸载后远程授权链路失效，状态链如实停在「插件未安装」，一键启动/修复可随时恢复
- **修复按钮语义收窄**：「修复 dsh 兼容栈」只在版本确实过低时出现（回退到验证栈）；版本够新但缺插件不再触发强制降级

- `pnpm run check:release -- --tag v0.2.0` 通过
