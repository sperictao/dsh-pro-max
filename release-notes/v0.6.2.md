# v0.6.2

系统托盘升级为 dsh web 的完整遥控器，并重制了 macOS 托盘图标。托盘新增「一键启动 / 一键关闭 / 一键重启 dsh web」三个菜单项，交互逻辑与首页按钮完全同源；图标则从彩色应用图标改为原插画墨线矢量化的单色 template 图，随系统亮暗模式与选中高亮自动适配，不再与系统托盘区格格不入。同时把 dsh 验证栈从 0.1.2-alpha.2 跟线升至 0.1.2-alpha.4。

## Changes

- **托盘菜单新增 dsh web 三键**：一键启动/关闭/重启按当前访问模式（本地/远程）走与首页完全相同的流程（`dshActions` 唯一实现），成功自动打开浏览器；菜单项可用性实时镜像首页按钮——未运行时仅「启动」可用、运行中仅「关闭/重启」可用、任一流程执行期间三键置灰。架构上托盘只是远端触发器：菜单点击经 `tray-dsh-action` 事件转发前端执行，避免第二份流程实现
- **macOS 托盘图标重制**：由原插画的角色剪影矢量化为单色 template 图（36px 对齐托盘 18pt 绘制尺寸，Retina 1:1 无二次缩放），墨覆盖率压在 ~1/3 保证小尺寸下读得出线条而非色块；Windows/Linux 沿用原彩色应用图标
- **dsh 验证栈升至 0.1.2-alpha.4**：版本闸门（`SUPPORTED_DSH_VERSION`）、修复（Repair dsh stack）目标与兼容文档同步；同线更高版本仍兼容，跨线或低于下限仍引导一键回退验证栈

## 验证

- 托盘图标真机菜单栏实测：亮/暗底均渲染为无背景的单色角色剪影，杀进程消除判定确认归属
- `vitest`：41 项全部通过（含托盘与首页共用的 dshActions 流程测试）；`cargo test`：77 项全部通过
- `tsc --noEmit`、`cargo clippy` 无错误；`pnpm run check:i18n` 无缺失无死 key
- `pnpm run check:release -- --tag v0.6.2`：版本三处一致、release notes 存在、bundle resources 路径有效

## 升级说明

- 无配置与数据迁移；v0.6.0+ 用户可直接升级
- 托盘三键与首页按钮行为等价：启动/重启沿用当前访问模式；既有边界不变——未开启「关闭时最小化到托盘」时主窗口关闭会销毁托盘，该状态下托盘不可用（与历史版本一致）
