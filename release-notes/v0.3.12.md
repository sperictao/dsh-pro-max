# v0.3.12

将远程授权配置从集成卡片迁移到设置页，配置项统一归设置模块，集成卡片只保留流程操作。

## Changes

- **远程授权模块迁移到设置页**：`Admin capability domain` / `Use capability domain` / `Extra allowed logins` 从集成卡片（远程模式下内联编辑）迁入设置页 **DeepSeek Harness** 分区，新增独立的 `RemoteAuthSection` 设置模块
- **集成卡片简化**：集成卡片不再内联编辑远程授权，只保留访问模式切换、一键启动/关闭、状态链时间轴与远程排障入口
- **文档与提示同步**：更新 `docs/dsh-remote-access.md`、`docs/dsh-remote-access-setup.md`，并把 Rust 启动失败提示从「集成卡片（远程模式）」改为「设置页 DeepSeek Harness 分区」
