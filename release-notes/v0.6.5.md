# v0.6.5

首页打磨收尾：诊断信息归位到一键按钮之下，操作区成为卡片第一视觉层次；三个一键按钮放大并加大行距，触达更从容；页面在宽窗下单列居中不再拉满边缘。同时精炼访问模式行卡文案，并补齐中文词典的动态词条——中文界面在任何状态下不再回落英文。

## Changes

- **诊断区下移**：检测错误提示、超版提示、远程告警盒从按钮行上方移至按钮行之下、Setup Progress 之前——操作前置、诊断随后；无诊断时整块不渲染不占位
- **一键三键放大**：高度 36→44px、内边距与字号同步增大（`style.css` 内 `.dsh-actions-row` 作用域覆盖，不改动市场/设置页共用的按钮配方）；按钮行上下留白加大一倍
- **首页单列居中**：内容列 `max-w-3xl` 居中，宽窗/最大化下不再拉满左右边缘
- **模式行卡文案两行制**：模式名即开关语义标签（本地访问/远程访问），说明小字只讲切换行为；zh 词典补齐状态球状态与时间轴步骤的动态词条（`check-i18n` 静态扫描盲区人工同步）
- **清理**：移除无引用的孤儿样式 `.home-backdrop`

## 验证

- `pnpm run check:release -- --tag v0.6.5`：版本三处一致、release notes 存在、bundle resources 路径有效

- 无配置与数据迁移；v0.6.0+ 用户可直接升级
