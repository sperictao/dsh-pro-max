# v0.1.0

首个版本。DSH 模块从 Codex Pro Max（dashi-taskboard-launcher）v1.10.0 拆分为独立应用：DeepSeek Harness 一键安装/启动与 Tailscale 安全远程访问。

## Features

- **dsh 本地访问**：检测 Node.js / dsh CLI 兼容性，一键安装 pin 版本并在 127.0.0.1:3899 启动 dsh Web UI，幂等启停
- **Tailscale 远程访问**：8 步时间线引导（node → install → plugins → tailscale → magicdns → start → serve → verify），每步失败给出原因与下一步
- **内置授权插件**：两个 pin commit 的插件（dsh-client-connection-authz + dsh-auth-tailscale）随安装包分发，自动装入 dsh web profile
- **远程授权配置**：可配置 admin/use capability 域名与额外允许的 Tailscale 登录名；不配置 capability 时远程特权接口恒 403
- **开机自启**：dsh web 服务经 OS 注册项（launchd / 启动文件夹 / autostart desktop）登录自起
- **壳基础设施**：42 族 tweakcn 主题、中英双语界面、托盘/单实例/窗口状态记忆、Tauri Updater 自更新

## 继承的基础设施（源自 Codex Pro Max）

- 发布管线：版本号三处同步校验（check:release）、5 平台构建矩阵、updater latest.json 生成、release notes 强制校验
- 文档体系：CONTEXT.md 术语与语义边界、7 篇 ADR（i18n 双机制、单实例、通知边界、主题演进、React 重写等）
