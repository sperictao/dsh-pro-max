# v0.8.21

本版修复较新 dsh 版本在本地模式下启动成功后，启动进度仍把“安装 DeepSeek Harness（dsh）”显示为未完成的问题。

## Changes

- **修复本地启动进度状态**：本地模式的 `install` 节点现在只依据 dsh CLI 是否已安装判断完成状态
- **正确支持较新跨版本线 dsh**：例如已安装 `0.1.6-alpha.1` 且本地启动成功时，“安装 DeepSeek Harness（dsh）”会保持绿色对勾
- **保持远程兼容性门禁不变**：远程模式仍要求 dsh 与当前授权插件栈兼容，不放宽远程授权安全与兼容性判断
- **保持启动行为不变**：本次仅修正检测结束后的时间轴状态推导，不改变 dsh 安装、启动、停止或访问逻辑
