# v0.8.32

上一版让应用纳管了官方 DeepSeek Harness 桌面应用，但桌面档的插件与配置只能在「插件 → 桌面应用」tab 里手输包规格、改原始 JSON。本版把**插件市场与模型配置按目标形态参数化**：同一套界面，web 档与桌面档都能用——目录浏览、一键安装、更新检测、启停、移除、模型与提供商编辑，桌面档全部可用。决策记录见 `docs/adr/0012`。

## Changes

- **形态角标**：发现、收藏、已安装三页的卡片右上角标出插件装在哪几档（Web / Desktop 并列）。桌面应用没开或桥接没连上时显示虚线的「Desktop ?」，悬停给出原因与下一步——**不会把「不知道」说成「未安装」**
- **按形态分行**：两档都纳管时，卡片底部每档一行，各自安装、更新、启停、移除。确认安装时可选「两档都装」：逐档安装、各自报结果，一档失败不回滚、不阻止另一档
- **已安装页合并两档**：同一插件一张卡、按形态分行；「全部更新」覆盖两档。桥接插件在桌面档显示为受管（不可移除、不可停用——停了它本应用就失去通往桌面档的通道）
- **桌面档与 web 档同一套规则**：安装白名单两档都生效；审计台账每条记录带上形态（`surface`）与该形态自己的 dsh 版本；构建脚本审批复用同一个对话框（放行交给桌面应用自己记录）。桌面档的更新**一律钉检测到的精确版本**——tag 与范围会被 pnpm 的发布冷却静默解析到旧版
- **自定义安装多一个「安装到」**（Web / 桌面 / 两者），目录之外的插件也能装进桌面档。它取代了原「桌面应用」tab 里的粘包规格入口
- **模型页形态切换**：两档都纳管时页头可在 Web / 桌面之间切换；桌面档读写的是它自己的配置补丁层，保存即生效（桌面应用写入前会按插件 schema 校验，不合法整次拒绝、原因原样显示）。桥接没连上时显示去向而不是空编辑器。凭据两档共用一份；导入写进当前选中的那档
- **「桌面应用」tab 收窄**：只留 web 档没有对应物的部分——桥接状态与一次性安装引导、内置 bundle 与插件行的开关、全部配置行的原始 JSON 编辑。用户装的插件只在市场里出现一次
- **可见性**：只要有一档在纳管，发现/收藏/已安装与模型页就在；诊断页诊断的是 web profile 的组合，只属于 web 档
- **桥接安装串改为 npm registry 包 + 精确版本**（`@sperictao/dsh-pro-max-bridge@0.1.5`），不再是 tarball 地址：桌面应用内嵌的 pnpm 11.7.0 对远程 tarball 有缺陷——包已在本机缓存时会写出缺 integrity 的锁文件条目、随即自己拒装，卸载重装必然复现

## 验证

- `cargo test`：**293 项通过**，含桌面档已装列表、结果映射、回执，以及模型域「撤掉 = 回写继承值」的单测
- 前端 `vitest`：**306 项通过**；`tsc`、`oxlint`（零 warning）通过；`check:i18n`：707 key，无缺失无死 key
- **变异验证**：9 处关键逻辑（写错形态、后一档抹掉前一档的失败、桌面更新不钉版本、拒绝审批后不续装、不可知当成未装、撤掉写 `{}` 等）逐一临时改坏，对应测试均失败
- `e2e`：**Chromium 与 WebKit 双引擎**全部通过，新增两档同时纳管的场景（卡片分行、装进桌面档不碰 web profile、已装页合并、模型页切到桌面档并保存到桌面档）
- **真机（桌面应用 0.2.0-rc.2）**：Rust 全链路探针对运行中的桌面应用实装、停用、启用、卸载一个插件并做更新检测，模型域写入一个探针提供商再撤回——之后桌面档 profile 与备份**逐字节一致**；另在真实 WKWebView 里点过关键路径（插件页分行与安装、已安装页停用与移除、模型页切档），测出并修复了「模型页切档时形态切换短暂消失」

## 升级说明

- **无破坏性变更、无迁移**。只纳管 web 时界面与上一版基本一致，卡片多出 Web 角标
- **桌面档的市场与模型功能需要桥接插件已连接**。还没装桥接的话，在官方桌面应用的 Plugins 页粘贴包规格 `@sperictao/dsh-pro-max-bridge@0.1.5` 安装一次。按上一版的 tarball 地址装过、或装时报 `ERR_PNPM_MISSING_TARBALL_INTEGRITY` 的，卸载后改用这个包规格重装
- **审计台账格式**：`plugin-audit.jsonl` 每行新增 `surface` 字段（`web` / `desktop`）；旧记录没有该字段，即 web 档
