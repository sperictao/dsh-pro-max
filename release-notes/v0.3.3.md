# v0.3.3

修复 Windows 版本检测的另一种输出形态（v0.3.2 的 BOM 修复未覆盖）。

## Fixes

- **Windows 版本检测仍报「无法解析 npm dist-tags 输出」**：部分 Windows npm/shim 的 `--json` 输出是**数组包对象** `[{"next":"x","latest":"y"}]`，与 macOS/Linux 的纯对象 `{"latest":"x"}` 不同，`serde_json::Map` 反序列化直接失败。`parse_dist_tags` 现接受对象 / 单元素数组 / 带 BOM 三种形态，数组形态下 key 顺序不保证的边界也已覆盖

## 验证

- `cargo test` 33 项通过（含数组形态、多元素数组拒绝、数组包非对象拒绝的回归用例）
- `cargo clippy -D warnings` 无警告
- `pnpm run check:release -- --tag v0.3.3` 通过
