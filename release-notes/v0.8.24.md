# v0.8.24

本版聚焦导航视觉统一：顶栏主导航与 Plugins 二级导航收敛为同一套无边框 segmented-control recipe，消除上一版顶栏分段盒子的双重框线与二级下划线 tab 的范式混杂。业务状态、后端命令和既有配置格式均未改变。

## Changes

- **顶栏主导航 segmented 无边框化**：容器只保留 muted 圆角底、不再描边——顶栏自带 `border-b`，双重框线随之消除；hover 只提字色，active 项白底微阴影浮起。
- **Plugins 二级导航切换为 segmented**：与顶栏共用同一 `APP_NAV*` recipe，两种导航语言各司其职（segmented = 视图切换，侧栏 accent 高亮 = 分区定位）；键盘与 ARIA 语义（`tablist` / `tab` / `tabpanel`、`aria-selected`、roving `tabIndex`）完整保留，a11y 层仅两行锚点适配。
- **样式清理**：移除 `.header-btn` 与下划线导航层（`market-navigation.css`）等被取代的遗留样式。

## 验证

- TypeScript、oxlint、Vitest（236 用例）全绿。
- E2E smoke 全部 step 通过，含 Plugins tab 键盘漫游（Home / End / ArrowLeft）与 `aria-selected` 契约，以及顶栏导航点击跳转。

## 升级说明

- **无破坏性变更、无迁移**。
- 仅 UI 视觉与导航结构；模型配置、插件状态、Settings 配置和后端命令接口保持不变。
