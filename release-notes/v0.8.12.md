# v0.8.12

模型模块按 PI-Desktop 的交互设计整体重构：AI 服务列表 + 预设服务对话框 + 模型双栏 + 五源配置导入；数据结构对齐 dsh llm-pi-ai 真实 schema——此前保存即丢失的模型级配置字段现在完整可用、往返无损。

## Changes

- **PI 式信息架构**：模型页重构为「AI 服务列表」——每行显示名称、默认徽标、凭据引用状态与 host·N 模型副行，行内提供设为默认 / 编辑 / 两步删除（3 秒未确认自动还原、失焦取消）；删除默认服务自动回退到下一可用服务；保存首个服务且无默认时自动设为默认。默认模型改为锚定菜单选择（按服务分组、搜索过滤、当前项勾选、键盘导航），不再手输
- **添加/编辑服务对话框**：32 个预设服务（deepseek、anthropic、openai、moonshotai、zai 等）选即回填路由键/显示名/接口地址/协议。预设表由 pi-ai 内置 provider 目录生成入库（`pnpm gen:model-presets` 再生，单一事实来源）；路由键命中内置目录时 dsh 自动继承端点、协议与模型目录，只需填 API Key 环境变量名。Base URL 形校验并自动剥离 `/chat/completions` 等尾路径
- **模型双栏**：左栏「该服务的模型」可手动获取上游列表（搜索、全选、失败按原因归类并重试）∪ models.dev 目录候选（带上下文窗口缩写）；右栏已选模型支持每模型高级设置——显示名、上下文窗口、最大输出、推理档（off..max 多选 + 每启用档 wire 拼写）、图片输入三态（跟随目录/仅文本/文本+图片）
- **数据结构对齐 dsh schema（往返无损）**：模型条目从纯 id 升级为结构化字段，服务级新增 headers 请求头编辑器（常用头预设、JSON 粘贴合并、凭据类保留头拒收）、请求超时、默认推理档。未在 UI 管理的高级字段（compat、重试策略等）在服务级与模型条目级逐层原样透传——修复了旧版保存把模型条目压成纯 id、丢弃手写字段的数据破坏；空模型列表不再写 `models` 键（继承内置目录而非清空路由）
- **五源配置导入**：一键扫描本机 Claude Code / Codex / OpenCode / Pi / CC Switch 的模型服务声明，按来源分组勾选导入，端点+凭据引用相同的自动跳过并计数；环境变量引用（`{env:VAR}`、Codex `env_key`）直接映射凭据字段，明文密钥永不读取、不展示、不落盘，只计数提示（内置目录路由可靠环境发现兜底）
- **生效语义修正**：查实 dsh 对 settings.yaml 为热加载（chokidar 监听 + llm-pi-ai 按请求解析），保存后即时生效——页面不再提示「重启 dsh web 服务」
- **目录状态行**：models.dev 目录快照新增来源/条数/更新时间展示与手动刷新按钮（进入页面 24h 自动刷新链路不变）

## 升级说明

- 无迁移；settings.yaml 既有内容完全兼容——含手写模型级字段的配置，本轮起经 UI 编辑保存不再丢失
- 「导入配置」扫描本机已知路径（`~/.claude`、`~/.codex`、`~/.config/opencode`、`~/.pi`、`~/.cc-switch`），来源缺失静默跳过；CC Switch 仅识别 legacy `config.json` 形态（sqlite 不扫）
- 每模型「默认思考档」不提供 UI：dsh schema 无该字段，默认档由服务级「默认推理档」与全局默认模型的推理档两级表达
- 供应商启停开关未提供：dsh schema 无 `enabled` 字段，删除服务即停用
