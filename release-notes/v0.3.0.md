# v0.3.0

dsh 版本检测、设置页 dsh 分区、访问模式运行时锁定与 i18n 覆盖完善。

## Changes

- **dsh 最新版本检测**：新增 npm registry 查询（`npm view @deepseek-ai/dsh version`，15 秒超时）。此前应用只显示 Launcher 锁定的兼容栈版本，无法感知 dsh 真实最新版
- **设置页新增「DeepSeek Harness」分区**：版本检测卡（已安装 / npm 最新版 / 验证过的兼容栈三行并列）与开机自启开关从集成卡片迁入——配置项归设置页，集成卡片只管流程操作
- **访问模式运行时锁定**：dsh web 运行中禁止切换本地/远程模式（切换只决定下次启动流程，不会改变运行中服务形态，允许切换只会造成「切了没反应」的困惑），锁定状态附明确解锁提示
- **i18n 覆盖补齐与防回归**：补前端 2 个、Rust 4 个缺失翻译；清理 i18n 表 24 个 codex-pro-max 残留死 key（133→109 条）；新增 `scripts/check-i18n.mjs` 校验（t()/tr() key 全覆盖 + 表内无死 key），挂进 CI Quality 工作流，本地可跑 `pnpm run check:i18n`

## 验证

- `pnpm run check:i18n` 通过：前端 109 key、Rust 表 109 条，无缺失无死 key
- `cargo test` 32 项、`vitest` 7 项、`cargo clippy -D warnings`、`tsc --noEmit` 全部通过
- `pnpm run check:release -- --tag v0.3.0` 通过
