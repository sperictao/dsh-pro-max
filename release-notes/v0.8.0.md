# v0.8.0

本版把插件模块补成完整生命周期：市场页拆「发现 / 收藏 / 已安装 / 诊断」四栏，装上之后的插件第一次有了启停开关、安装护栏、更新兼容门禁、失败归因与深度诊断；进程执行链补上超时与取消，挂死的子进程不再拖死界面；设置页改脏草稿保存条，保存动作有了明确的「保存 / 放弃」语义。

## Changes

- **插件启停开关**：已安装页可翻转插件的下次启动启用状态——在 profile 的 `cordis.patch.yml` 行级写/删 `{id, name, disabled: true}` 覆盖行，其余字节原样保留（serde_yaml 往返会静默剥掉 loader 依赖的 `!!js` 表达式标签）；重复启停内容未变化免写盘不记台账；已装卡新增 text-switch 状态胶囊开关（移植自 codex-pro-max 配置看守参数行），配「重启 dsh web」就近入口（复用一键重启与启动时间线），重启后生效；受管授权插件不走此通道；移除插件时清理孤儿停用行，防重装继承停用态
- **安装护栏**：安装/重装退出码 0 之后四道保护——落盘校验（npm 形态键可预知，退出码成功但键未落盘即未生效）→ 重复挂载剥离（CLI 的 bundle 对账会把组合树里已由 patch 行挂载的包重新加进 `dsh.profile.bundles`，只剥本次新增且已由 patch 行挂载的条目并透传 notice）→ 重复入口 id 回滚（新包撞上既有占用时经官方 remove 路径回滚，绝不写共享 disabled 行）→ `--dump-config` 启动预检（组合失败且输出牵连新包才回滚，无关失败如实报告不动任何东西）；协议形态重装（github:）无法唯一定位回滚目标，只校验与预检、不自动回滚
- **更新兼容门禁**：目标包 manifest 声明 `dsh.engines.dsh`（仅认 `>=X.Y.Z` 形态）而宿主 dsh 不满足、或声明形态/宿主版本无法核实（fail closed）时，更新按钮禁用并排除出批量更新；判定复用更新检测同一 `/latest` 响应并落 24h 磁盘缓存；发现页对可见卡片批量查询兼容性，提供「仅看兼容」筛选与不兼容提示
- **失败可观测**：pnpm 失败按根因分类（pnpm 大版本漂移、store 不一致、锁文件缺完整性哈希、patch 失效、Windows 文件占用等），每类给可执行的下一步（静态双语整句，zh 词典精确命中）；安装/移除 busy 态可取消，超时（装 15min / 卸 2min）到点杀进程并回收、已捕获输出保留；市场渲染崩溃由错误边界兜成恢复面板（重载或复制错误详情）；更新动作先读目录侧更新说明弹窗再执行；疑似终端/CLI 插件（运行 shell 命令）安装前警示
- **诊断页**：市场第四栏读 `dsh --dump-config` 组合事实——重复入口 id（下次启动必炸）与孤儿 patch 行（引用了不存在的包）逐条点名并给出下一步；支持重跑与一键复制
- **删除无效 compat 写入机制**：历史版本往 `cordis.patch.yml` 写的 `dsh-pro-max-compat` 条目因上游 loader 补丁方言（id+name 行是覆盖而非插入）从未生效，只留 `patch: entry "dsh-pro-max-compat" not found` 孤儿警告；写入机制（insert/rewrite/ensure 全链）删除，启动、修复与版本安装路径顺手清理存量条目
- **进程执行韧性**：`run_capture_lines` 支持超时与取消令牌——被杀路径不 join 读线程（管道可能被孙进程持有），改取共享缓冲快照，挂死/取消都不再无限挂住调用方；`dsh --version` 加 10s 硬超时，dsh 偶发挂起不再拖死版本胶囊与兼容门禁
- **设置页脏草稿保存条**：落盘快照作为脏状态唯一事实来源——干净草稿不渲染保存条，出现修改后底部条提供「保存 / 放弃」，放弃即回滚草稿；语言切换即时落盘改基于已保存快照写盘，不再夹带未保存草稿；移除逐区块即时保存的旧提示（「System Behavior」分区标题与授权已保存 toast）
- **市场页结构**：二级导航拆「发现 / 收藏 / 已安装 / 诊断」，浏览页只管浏览与安装（已装匹配卡只读呈现安装事实与启停状态），2700+ 条目录分页渲染防卡顿；构建脚本审批重跑返回与安装同构的结果，护栏 notice 随 toast 透出

## 升级说明

- 无破坏性配置变更；存量 `cordis.patch.yml` 里的 compat 条目会在下一次启动/修复/版本安装时自动清理，无需手工处理
