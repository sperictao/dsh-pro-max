# v0.3.2

修复两个 Windows / 启动流程的 hotfix。

## Fixes

- **Windows 版本检测失败**：`npm view dist-tags --json` 在 Windows 经 `cmd /c` 执行时输出带 UTF-8 BOM 与首尾换行，`parse_dist_tags` 解析前统一剥除，修复「检查失败: 无法解析 npm dist-tags 输出」
- **一键启动打开两个浏览器标签页**：dsh CLI 默认启动后自动打开浏览器，与前端 `openUrl` 叠加导致打开两次。`spawn_dsh_web` 与开机自启脚本统一加 `--no-open`，浏览器打开只由前端在用户点击「一键启动」后控制（顺带修复了开机自启也会弹一次浏览器的问题）

## 验证

- `cargo test` 33 项通过（含 BOM/换行包裹的 Windows 输出形态回归用例）
- `cargo clippy -D warnings` 无警告
- `pnpm run check:release -- --tag v0.3.2` 通过
