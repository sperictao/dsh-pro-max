# v0.8.23

本版集中完成一轮 Better UI 收口：统一应用壳层、共享控件、Plugins 二级导航、Models 与 Settings 工作区的布局与交互，并补齐 Plugins 的键盘与 ARIA 语义。业务状态、后端命令和既有配置格式均未改变。

## Changes

- **应用壳层统一**：顶级导航迁到共享 segmented-control recipe，窄窗口支持换行/横向滚动，页面 gutter 由统一响应式变量管理。
- **共享控件交互一致化**：按钮、输入框、选择器、开关、品牌入口与图标按钮统一 hover / focus-visible / pressed 反馈；紧凑按钮点击高度从 24px 提升到 28px。
- **Plugins 二级导航层级优化**：改为轻量 underline tabs，与应用级 segmented nav 明确区分；窄窗口可横向滚动并沿共享 gutter 对齐。
- **Plugins 键盘与 ARIA 语义**：加入 `tablist` / `tab` / `tabpanel`、`aria-selected`、roving `tabIndex`，支持 ArrowLeft / ArrowRight / Home / End；保留 `market-installed` 等已有稳定 ID 与 selector。
- **Models 工作区间距统一**：加载态与正常态都使用共享响应式 page gutter，窄窗口 16px、较宽窗口 24px。
- **Settings 侧栏迁到共享 recipe**：active / inactive 状态显式化，统一语义色、focus ring、pressed feedback，同时保留原有 `aria-current` 与设置状态机。
- **Settings 内容版心统一**：右侧设置内容复用 `app-page-width`，避免宽屏无限拉伸；dirty footer 保持全宽表面，但按钮与提示和正文列对齐。
