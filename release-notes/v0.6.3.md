# v0.6.3

首页重构：引入 codex-pro-max 同款「状态球」作为页面主视觉，dsh 服务状态一眼可读。页面重组为四段——大写 DEEPSEEK HARNESS 标题行、状态球区、访问模式行卡、dsh 卡片——状态文字、模式说明、诊断信息各归其位，重复展示全部收拢。本版仅前端界面重构，dsh 一键流程、托盘与访问模式的行为与 v0.6.2 完全一致。

## Changes

- **状态球**：四态径向渐变球体（运行绿✓ / 停止灰✕ / 进行中黄▶ / 出错红✕），常驻呼吸动效，悬停定住并放大 1.05 倍；球下状态文字颜色随态。视觉移植自 codex-pro-max，尺寸取其紧凑档适配 960×680 默认窗口；悬停放大改为「移除动画 + 静态 transform」，修复源项目写法中暂停动画帧覆盖 scale 声明导致放大不生效的问题
- **四段布局**：大写标题行（含版本胶囊与修复/卸载插件操作）上移至球上方；访问模式说明小字自卡片迁至球区状态文字下方，随本地/远程模式切换；访问模式行卡独立成段置于球区之下，「看完状态 → 切模式 → 下方应用」动线更顺
- **dsh 卡片瘦身**：移除与球区重复的状态文字（诊断信息保留：检测错误、超版提示、远程告警盒按需出现，无诊断时整块不渲染不占位）；地址行独立成行——URL 胶囊靠左、复制/打开靠右，超长地址得体截断；三个一键按钮水平居中
- **状态文案单一来源**：状态行文案提取为 `statusLineKey`，球区与卡片诊断共用同一推导，不另造字符串（零新增 i18n key）
