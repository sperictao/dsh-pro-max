# v0.8.19

本版统一了应用主要工作区的内容宽度。此前首页使用一套响应式最大宽度，而插件模块的 Discover / Favorites / Installed / Diagnostics 页面会随窗口拉满、模型页面又固定在另一宽度，导致顶层模块切换时内容边界明显跳动。现在主页、插件内容页和模型页共用同一套响应式页面宽度规则，整体视觉基线保持一致。

## Changes

- **统一顶层内容宽度**：抽取主页现有的响应式宽度规则作为共享页面布局基线：默认 48rem，`lg` 56rem，`xl` 64rem，`2xl` 72rem
- **插件模块对齐主页**：Discover、Favorites、Installed、Diagnostics 四个内容页全部按主页宽度居中；二级导航与滚动容器仍保持全宽，滚动条位置不变
- **模型模块对齐主页**：Model Configuration 主页面及加载状态统一采用相同响应式宽度，不再固定于单独的 `max-w-4xl`
- **弹窗与业务逻辑保持不变**：插件安装/更新等 Dialog 继续使用各自尺寸；未修改 store、命令调用、状态机或配置持久化逻辑
