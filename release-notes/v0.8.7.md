# v0.8.7

本版放开 dsh 版本安装的版本闸门：任何 dist-tag 指向的版本均可安装，不再因「与内置插件栈不兼容」灰掉安装按钮或被后端拒绝。兼容性判定保留为纯展示标记（红字警示 + 状态胶囊），安装 incompatible 版本成功后追加 toast 提示授权插件可能失效。

## Changes

- **删除版本安装闸门**：`dsh_install_version_once` 不再调用 `dsh_version_is_compatible` 拦截跨线版本——任何可解析版本均可安装。此前 `0.1.5-alpha.1` 等跨线版本被后端直接拒绝（"outside the supported line"），即使前端按钮放开也会安装失败
- **前端安装按钮不再因 incompatible 灰掉**：`DshVersionSection.tsx` 按钮 `disabled` 条件从 `busy || tag.incompatible` 收窄为 `busy`——不兼容的版本行保留红色「与内置插件栈不兼容」警示文案，但按钮永远可点
- **安装成功后风险提示**：安装 incompatible 版本成功后，除常规的「dsh 已更新到 X」toast 外，追加「授权插件可能不兼容；若本地与远程访问失效，可在启动失败诊断中一键禁用肇事插件」info toast——风险如实披露但不阻断用户选择
- **i18n 清理**：删除已废弃的 `"dsh {{version}} is outside the supported line..."` 错误文案（zh + en），新增授权插件风险提示文案（zh + en）
