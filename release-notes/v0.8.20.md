# v0.8.20

本版完成两项收尾：建立前端设计系统 lint 基线，并统一设置模块各页面的右侧内容宽度。重点是让后续 UI 修改更容易保持一致，同时修正设置页在不同分区切换时内容宽度跳动的问题。

## Changes

- **新增 @shadcn/lint + Oxlint 设计系统检查**：将设计系统约束接入现有 Quality CI，覆盖组件重样式、原始颜色、非布局 arbitrary value、JSX inline style、动态 class 与未知 class 等规则
- **设计系统边界收敛**：明确 `src/shared/components/**` 与 `src/shared/lib/ui.ts` 的实现层例外，业务 UI 继续复用共享 recipe 与语义 token
- **清理普通 inline style**：更新进度、模型虚拟列表、固定行高和 Toast 淡出等场景改为静态 Tailwind class + CSS 变量/状态 class，避免业务层 JSX presentation style
- **补齐语义 utility 注册**：将 `settings-section`、`install-log`、`app-page-width` 等应用级语义类纳入 Tailwind v4 可识别范围
- **设置模块宽度统一**：通用、关于、dsh 版本、开机自启、远程授权的右侧内容区域与“外观”页对齐，移除原有 `max-w-2xl` 造成的窄列显示
- **保持功能行为不变**：本次设置页调整仅涉及布局宽度；store、命令调用、持久化、更新器和远程授权逻辑均未修改
