# v0.3.5

修复远程访问 WebSocket 握手失败，并更新 dsh 与授权插件的兼容策略。

## Fixes

- **远程访问验证报 WebSocket 握手失败（502）**：授权桥接层请求体上限恢复为 300 MiB，与 dsh 默认 200 MiB 图片上限经 Base64 编码后的约 267.7 MiB 请求体对齐；`/api/events.host` 现在可以正常注册并经 Tailscale Serve 完成 `101 Switching Protocols`
- **新版 dsh 被 Launcher 回退到旧 RC**：兼容版本改为由 web profile 的实际依赖下限驱动，修复动作跟随 npm `@next` 并显示真实安装版本；profile patch 的新增、幂等更新与完整清理都已覆盖带注释的 `cordis.patch.yml`
- **授权插件组合升级**：内置 authz / Tailscale 插件更新到 rc.8 兼容栈，依赖范围不再硬等旧 dsh 版本；打包前同时校验 submodule 精确 pin 与干净工作树，拒绝把本地脏改动伪装成 pinned tarball
- **设置页长名称换行**：加宽左侧导航并禁止菜单项换行；主题测试同步到新的共享模块路径

## 验证

- 本机独立 `v0.3.5` debug App（npm `@next` 当前为 dsh `0.1.1-rc.2`）一键启动 8 个步骤全绿
- 本地与 Tailscale 远端首页均返回 200，`/api/events.host` WebSocket 均返回 101，非受信 Host 返回 403
- Rust 36 项、authz 插件 40 项、Tailscale 插件 22 项、主题 5 项、Vitest 7 项全部通过；Clippy 与前端构建通过
- `pnpm run check:release -- --tag v0.3.5` 通过
