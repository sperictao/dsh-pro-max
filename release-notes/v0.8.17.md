# v0.8.17

前端稳定性与 UI 一致性收口版：完成 Models / Market 最近一轮 UI/UX Audit 的剩余修复，同时加强插件市场写操作串行化、生成物一致性与 Rust 全目标 CI 门禁。

## Changes

- **Market Update all 审批状态机修复**：批量更新遇到 build-script approval 后选择保持脚本禁用，不再让队列永久卡住；当前项会被跳过并继续剩余更新
- **审批语义完整保留**：build approval 现在保留 install / update 与 silent 上下文，审批成功后的 Toast、更新徽标与批量统计按真实操作收敛
- **Market 写操作串行化**：插件安装、更新、删除及批量更新统一遵守单写操作约束，避免共享 web profile 上 IPC/store 并发交错
- **ProviderDialog 键盘可访问性**：打开弹窗时建立明确初始焦点，并实现 Tab / Shift+Tab 焦点约束；关闭后仍恢复到原触发控件
- **Service Picker 指针边界修复**：自动聚焦后，静止鼠标不再被误判为主动 hover；只有真实指针移动才切换高亮选项
- **Models credential 语义收敛**：readiness 与状态查询从旧的 env 命名统一迁移到 DSH credential plane 语义
- **UI 语义 Token 收敛**：破坏性按钮、状态颜色、卡片、Modal、Toggle、辅助文本等进一步统一到共享语义 recipe / token
- **CI 与生成物一致性加强**：Clippy 扩展到 `--all-targets`；`cargo test` 后校验 ts-rs bindings 与 Cargo.lock 未产生未提交差异；release 检查同步验证 Cargo.lock workspace version
