# v0.3.4

修复两个 Windows 实机问题。

## Fixes

- **一键启动后 dsh 被装回锁定版本（Windows）**：`which("dsh")` 在 Windows 用 `where dsh`，原实现取第一行匹配——若 `dsh.ps1` 排在 `dsh.cmd` 前面，cmd /c 执行 `.ps1` 失败导致 `dsh --version` 返回非零，被误判为「未安装」而触发装回 rc.6。现优先挑 cmd 可直接执行的 `.cmd/.bat/.exe`，找不到才回退第一行
- **开启自启时授权插件安装失败（Windows）**：`install_auth_plugins` 首次 `dsh plugin add` 失败时，先 `plugin remove` 清理 profile 残留再重试一次——覆盖 pnpm 在 profile 目录状态损坏（node_modules 硬链接跨版本失效 / lockfile 与 store 路径不一致）导致 add 失败且无有效 stderr 的场景；错误路径现在带完整 stderr

## 验证

- `cargo test` 33 项、`cargo clippy -D warnings` 通过
- 本机验证 `dsh plugin remove→add` 往返正常
- `pnpm run check:release -- --tag v0.3.4` 通过
