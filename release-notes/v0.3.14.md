# v0.3.14

修复执行长流程时切换页面后当前状态丢失的问题：将 DSH 运行时/版本管理/自启状态上移到全局 store，页面组件卸载后重挂载仍能恢复原现场。

## Changes

- **一键启动 dsh web / 停止 / 修复 / 远程重检状态跨页保留**：`DshCard` 的状态从组件本地 `useState` 迁移到全局 Zustand store，切换 Home 与 Settings 再返回时，正在执行的流程、按钮 busy 状态、失败时间轴不再丢失
- **dsh 新版安装状态跨页保留**：`DshVersionSection` 的版本列表、检查中、安装中状态迁移到全局 store；正在安装或已有检查在跑时切页回来不会触发新的检查覆盖现场
- **dsh 开机自启状态跨页保留**：`DshAutostartSection` 的检测结果与切换 busy 状态迁移到全局 store，避免切页后开关状态重新加载
- **应用自身更新进度跨页保留确认**：updater 状态原本已在全局 store，新增 unmount/remount 测试覆盖“更新中 + 下载进度切页后仍在”的行为
- **清理旧实现**：删除已无引用的旧合并版 `DshSection.tsx` 与其测试
