# v0.3.1

dsh 版本检测升级为全 dist-tag 一览 + 应用内逐版本安装；设置页导航与卡片布局优化。

## Changes

- **全 dist-tag 版本检测**：`dsh_check_latest` 从只查 `latest` 改为 `npm view dist-tags --json`，一次返回所有 tag→version 映射（当前 registry 为 `latest→0.1.0-rc.7`、`next→0.1.0-rc.8`），每行带「已安装」「未验证」状态标记
- **应用内逐版本安装**：新增 `dsh_install_version` 命令，版本卡每行提供「安装」按钮，可切换到任意 tag 指向的版本（含低于验证栈的版本——风险由「未验证」标记如实披露）；装完若 dsh web 在运行则自动重启
- **设置页导航分组**：侧栏分为「应用」（通用/外观/关于）与「集成」（DeepSeek Harness）两组，层次更清晰
- **dsh 分区与关于页卡片化**：版本卡改为语义化定义列表 + tag 表格，验证栈说明文案带具体版本号；关于页版本号移至标题副标题位，GitHub 入口收进统一风格卡片

## 验证

- `cargo test` 33 项通过（含新增 `parse_dist_tags` 单测）
- `pnpm run check:i18n` 通过：前端 115 key、Rust 表 111 条，无缺失无死 key
- `vitest` 7 项、`cargo clippy -D warnings`、`tsc --noEmit` 全部通过
- GUI 验证：导航分组、卡片布局、错误路径截图确认
- `pnpm run check:release -- --tag v0.3.1` 通过
