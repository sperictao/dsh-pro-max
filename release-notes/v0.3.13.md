# v0.3.13

调整应用导航与设置模块结构：顶部“集成”tab 改为 Home，设置页原 DeepSeek Harness 区域拆分为多个独立设置页面。

## Changes

- **顶部 tab 重命名**：将原 `Integrations` tab 改为 `Home`，中英文导航文案同步更新
- **设置导航分组重命名**：设置页侧栏中的“集成”分组改为 `DeepSeek Harness`
- **设置页拆分**：原单一的 DeepSeek Harness 设置页拆分为三个独立页面：
  - `dsh Version`：版本检测与逐版本安装
  - `Boot Auto-start`：dsh 开机自启
  - `Remote authorization`：远程授权配置
- 新增 `DshVersionSection` / `DshAutostartSection` 组件，`RemoteAuthSection` 独立成远程授权设置页
