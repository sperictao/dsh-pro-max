# v0.8.14

Provider Studio 交互与可靠性收口版：在 v0.8.13 的模型配置能力基础上，对 Models / ProviderDialog / ModelPanes 进行了完整 UI/UX Audit，重点改善主流程层级、异常恢复、键盘与可访问性、模型批量操作，以及 Provider 配置中的状态一致性。

## Changes

- **Models 主界面重构**：优化 Default Model、Reasoning Effort、Provider 卡片与 Catalog 的信息层级；低频 Provider 操作收敛为图标动作，技术说明下沉，减少主界面视觉噪音
- **Add / Edit Provider 主流程**：已知服务新增路径收敛为 Service → API Key → Models → Save；Custom endpoint 自动聚焦 Display Name、自动派生 Route key，并保留手工覆盖能力；Edit 模式加入真实 dirty-state，未修改时不允许无意义保存
- **连接测试与模型发现**：ProviderDialog 与 Provider 卡片的 Test connection / Fetch list 状态彼此独立；多 Provider 快捷操作避免并发状态互相覆盖；成功/失败反馈明确标识所属 Provider
- **异常恢复更可靠**：Save provider 失败后保留草稿、只显示一个上下文错误，并在用户继续修改时退出 stale error；Test connection 使用请求 revision 防止旧请求结果污染已修正的新草稿
- **Custom Base URL 校验**：无效 URL 在 blur 时不再被静默改写；错误与输入框通过 `aria-describedby` 关联；仍然无效的修正过程持续显示原因，直到输入真正有效后再恢复 Test / Save
- **关闭与键盘行为**：ProviderDialog 的 Cancel / Escape / backdrop 统一处理未保存修改；dirty 状态要求显式 Discard，真正关闭后焦点返回 opener；Service Picker 与 Model Search 的 Escape 不再误关闭整个 Dialog
- **Service Picker 可访问性**：修复 neutral Enter 误选 Custom endpoint、Escape 冒泡和下拉层被 Dialog overflow 裁剪；补齐 `aria-controls` / `aria-activedescendant` 与稳定 option identity
- **ModelPanes 搜索与选择**：Search model ID 严格按 ID 匹配，显示命中数量，0 结果禁用 Select all；支持 Esc 清空；Select all 在搜索态只影响当前命中项，单项 checkbox 与右侧 Model settings 状态保持同步
- **模型增删与 Advanced**：新增 Custom model 后立即展开目标行；Remove model 使用明确 destructive 语义并清理 stale expansion；Model Advanced 始终保留 canonical Model ID，Alias 作为辅助信息，Context / Max output 摘要实时反映 override
- **Thinking / Image input 继承语义**：未显式 override 时明确展示 `Follow catalog` 的实际继承结果；Thinking levels 的 wire spelling 生命周期与 Image input 的 inherit → override → reset 均加入独立回归保护
- **Headers editor**：HTTP header name 按大小写不敏感 identity 归一；Common headers 与 JSON import 采用 case-insensitive upsert；JSON import 改为原子校验，避免部分字段静默成功；Authorization / x-api-key / Cookie 等凭据头仍不会落盘
- **Catalog Refresh / Retry**：刷新中不再同时显示旧 snapshot 状态；失败只保留单一 inline error；Retry 开始后立即清理 stale failure，恢复成功后明确显示新的 models.dev 状态
- **Import configuration**：默认只勾选可直接复用的 env / none 凭据来源；literal key 条目保持可见但默认不选；隐藏空来源并改善搜索计数和条目信息层级
- **系统化 UI Audit**：新增 31 条正式 Models UI Audit workflows 与对应确定性浏览器 capture，覆盖主流程、错误恢复、键盘操作、并发状态和保存语义，作为后续回归门禁

## 升级说明

- 无配置迁移；现有 `settings.yaml` 保持兼容
- Provider / Model 的存储结构和 IPC 契约未做破坏性变更
- API Key 仍只保存环境变量名，不保存明文 secret
- Custom Base URL 的无效输入现在会保留原值并持续提示，只有合法 `http://` / `https://` URL 才会进入规范化流程
- Headers JSON import 现在是全量原子校验：任意 value 不是字符串时整次导入不会部分生效
- dirty ProviderDialog 关闭时会要求显式 Discard，以避免误操作丢失未保存配置
