# v0.8.5

本版给市场发现页补上重启就近入口，并带上 v0.8.4 之后的两个修复：市场页 Custom install 入口在 v0.8.4 中被误删现予恢复；安装取消/超时的击杀等待改有界，取消反馈更快，同时终结了 v0.8.1 起 Quality 的时序失败。

## Changes

- **发现页页头新增「Restart dsh web」**：装完/启停插件后要重启 dsh web 才生效，此前必须切到已装页才能重启；现发现页页头就有重启按钮，复用 Shell 域一键重启（先关后启、启动时间线、busy 守卫都在 dshActions），busy 镜像与已装页同一套。页头按钮顺序统一为 Refresh < Custom install < Restart dsh web
- **恢复市场页 Custom install 入口**：d240066 拆分并行会话的按钮换位改动时误将"旧位置删除"半边带入提交，Custom install 按钮随 v0.8.4 发布缺失（Quality 前端 4 项测试失败暴露），af9c9a2 按 v0.8.3 原位恢复
- **安装取消/超时的击杀等待改有界**：击杀后由无条件睡 1s 改为有界（1s 封顶）等 stdout/stderr 读线程 EOF，无孙进程的常见情形毫秒级返回，取消安装的 busy 清除随之变快；两个击杀时序测试击杀窗 200/300ms 提到 800ms（Linux CI 高负载下 node 冷启动可达数百 ms，窗短于冷启动会让子进程来不及写入，"保留部分输出"断言落空——v0.8.1 起 Quality 连续失败即此因，快速击杀仍由总耗时上界断言兜住）

## 验证

- `cargo test`：164 项全部通过（含取消击杀时序用例）；前端 `vitest` 112 项全部通过（含发现页页头顺序与重启动作新用例）；`tsc`、`check:i18n` 通过
- `check:release --tag v0.8.5` 通过

## 升级说明

- 无破坏性变更、无迁移。发现页重启按钮与已装页是同一动作，busy 期间全局互斥
